# Student Grade Tracker

A simple command-line application built with Python to manage student marks and calculate grades.

## Features

- Add students and subjects
- Calculate average marks
- Find highest and lowest marks
- Assign grades
- Search students
- Save results to JSON

## Technologies

- Python
- OOP
- Dictionaries
- JSON
- Exception Handling

## How to Run

```bash
python Student_grade_tracker.py
